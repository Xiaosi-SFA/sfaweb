## 快速开始

使用 `pnpm dev` 启动本地开发服务器，访问提示的本地地址即可预览站点。

```bash
pnpm install
pnpm dev
```

## 特性一览

- 内容集合：通过 frontmatter 管理标题、日期、标签等元数据
- 列表卡片：统一 16:9 封面、标题、摘要与标签
- 详情页：左侧目录 + 推荐文章，右侧正文，两栏布局
